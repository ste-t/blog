# Blog

This repository powers my personal blog, built with [Hugo](https://gohugo.io).

I use it to share posts about technology, projects, and ideas I’m exploring.

## 🚀 Features

- Easy-to-mantain static site
- Written in Markdown for simplicity, efficiency and minimalism
- Multilingual support

## 📚 Structure

- `content/{langCode}` → Language directory
- `content/en/posts` → Blog posts

Check out the live site here: [blog.tste.dev](https://blog.tste.dev).
